# Crit 8 reflection

## What was the breakthrough that moved the work forward?

The first sky stretched into a rectangle so the stars looked wrong, my live checks accidentally left fake test stars behind, and one timing-based test passed when rerun even though it was not reliably proving the behaviour. I learned that a passing test is not automatically good evidence, and small visual or data assumptions can change the meaning of the whole project.

## What did this work change about who I want to be as a software developer?

I picked Overlap because it felt more personal and less like a normal app: the main interaction is simply leaving a quiet trace that someone else can discover later. In Crit 9, I will define "being here" carefully before building real-time features, and make every live test either read-only or clean up after itself.
